# ФК «Севастополь» — сайт клуба ⚓⚽

Современный дизайн-концепт сайта футбольного клуба «Севастополь» для **GitHub Pages**.

## 🚀 Запуск

Сайт — чистый статический HTML/CSS/JS без сборки.

**Локально:**
```bash
# любой статический сервер, например:
python -m http.server 8080
# затем откройте http://localhost:8080
```

**GitHub Pages:**
1. В настройках репозитория: *Settings → Pages → Source: Deploy from a branch → `main` / `(root)`*
2. Сайт будет доступен по адресу `https://superpirov.github.io/sevfootball/`

## 🗂 Структура

```
index.html      — страница-лендинг со всеми разделами
css/style.css   — стили (тёмная «морская» тема, glassmorphism, адаптив)
js/data.js      — все данные клуба (состав, таблица, матчи, новости) — редактировать здесь
js/main.js      — интерактив: отсчёт до матча, фильтры состава, анимации
assets/logo.svg — векторная эмблема-заглушка (замените на официальную!)
```

## ✨ Что внутри

- Hero с обратным отсчётом до ближайшего матча и анимированными волнами
- Бегущая строка с достижениями
- Календарь матчей + последние результаты + бомбардиры
- Турнирная таблица LEON-Вторая лига Б (подсветка лидера)
- Состав с фильтром по амплуа (25 игроков)
- Новости, история-таймлайн, витрина трофеев
- Тренерский штаб, стадион, Fan Zone (билеты/абонементы), контакты

## ✏️ Как обновлять данные

Все игровые данные вынесены в `js/data.js` — достаточно отредактировать массивы
`PLAYERS`, `STANDINGS`, `UPCOMING`, `RESULTS`, `NEWS` и сделать push.

Также обновите дату ближайшего матча в `index.html`:
`<div class="countdown" data-next-match="2026-09-22T16:00:00+03:00">`

## 📌 Примечания

- Эмблема — собственная векторная заглушка, замените `assets/logo.svg` на официальную символику клуба (см. раздел «Символика» на fcsevastopol.ru).
- Данные актуальны на сентябрь 2026 (источник: fcsevastopol.ru).
- Это фан-сайт / дизайн-концепт, не официальный ресурс клуба.
